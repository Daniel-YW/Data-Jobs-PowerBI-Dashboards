# Data Jobs Dashboard (Power BI)

## Overview
This project is a Power BI dashboard that analyzes the global data job market.  
It explores job postings to extract insights on salaries, skills demand, job roles, and geographic distribution.

The goal is to help data professionals and recruiters understand hiring trends and market needs through clear visual analytics.

---

## Objective

- Analyze trends in data-related job postings  
- Identify the most in-demand skills  
- Compare salary distributions across roles and regions  
- Understand the global distribution of data jobs  
- Build an interactive Power BI dashboard for decision-making  

---

## Dataset

The dataset contains job postings related to data roles such as:

- Data Analyst  
- Data Scientist  
- Data Engineer  
- BI Analyst  

It includes fields such as:

- Job title  
- Salary 
- Location  
- Skills required  
- Company / industry

## Dashboard Features

### 1. Salary Analysis
- Average salary by job role  
- Salary distribution  
- Comparison across regions  

### 2. Skills Demand
- Most required skills  
- Skills frequency by job type  

### 3. Job Market Overview
- Number of job postings by role
  
### 4. Geographic Insights
- Jobs distribution by country / region  
- Remote vs on-site trends
